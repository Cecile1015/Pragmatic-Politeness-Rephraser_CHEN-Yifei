## 项目介绍

**泡泡改写（2P Rephraser）** 是一个基于 Python + Flask 的 Web 应用，核心功能是把用户输入的普通话汉语文本，依据不同的**应用场景**和**目标语言**，改写成多个体现不同**礼貌程度**和**语用特征**的表达版本。

### 项目目标

1. **学术辅助** —— 帮助从事语言学研究的学者和学生，直观对比同一交际意图在不同语用策略下的表达差异，为语用学研究提供数据支撑和教学素材。
2. **生活应用** —— 辅助用户在真实社交场景中选择得体的表达方式，提升跨文化 / 跨语境的沟通能力。

### 目标用户

- **主要用户**：从事语言学、社会语言学、语用学研究的学者和研究生
- **次要用户**：对语用表达感兴趣的语言学习者、希望提升社交表达能力的普通用户

## 功能特性

### 三大页面（底部图标切换）

| 页面 | 功能 |
|---|---|
| 🖊 **任务执行区** | 输入文本 → 选择场景与目标语言 → 一次性输出多档改写结果 |
| 🗂 **历史改写存储区** | 按目标语言分区归档（含地区旗方块），可展开查看历次完整结果 |
| 🎯 **游戏交互** | 每日语用挑战与自由练习，自动评分、给改进建议、连续打卡 |
| 👤 **个人专区** | 昵称、积分、场景解锁进度、收藏夹、数据导出 |

### 游戏交互：每日语用挑战

给一个真实生活中会让人卡壳的语境（例如「你不同意老板在会上提出的方案，需要当场表达异议」），
由用户自己写出他认为最得体的说法，系统评分并给出改进建议。

- **题库**：20 道题，每题对应一种言语行为（表达异议、拒绝请求、纠正上级、接受赞美、承认失误……），
  全部是语用学意义上的**面子威胁行为**（Face-Threatening Act），并标注了场景、难度与语用焦点。
- **每日挑战**：20 天为一轮，每轮把题库洗一次牌，轮内不重样；
  选题是**确定性**的（由日期决定），不需要数据库，同一天所有用户拿到同一题。
  日期由浏览器提供，因此按用户本地时区计算，不会因为服务器在 UTC 而错位。
- **自由练习**：随时抽题，不限次数，不计入打卡与积分，但作答会存进记录。
- **评分**：三个维度各 0–100 分 —— 得体度 Appropriateness／策略性 Strategy／自然度 Naturalness，
  外加总评、用到的语用手段标签、改进建议，以及「在你原话基础上的改进示范」。
- **积分**：80 分以上 +5，60–79 分 +3，60 分以下 +1；连续打卡 ≥3 天额外 +1，≥7 天额外 +2。
- **导出**：「导出我的作答 (CSV)」把「情境 → 作答 → 三维得分」导成 CSV，
  可直接拖进 Excel 或 R 做分析，适合让受试者自己发回给研究者。

### 核心能力

- **五档礼貌程度**，按从最粗鲁到最礼貌排序，中英双语命名：

  | 档位 | 中文 | 英文 | 色条 |
  |---|---|---|---|
  | 1 | 非常直接 | Very Direct / Imperative & Rude | 🔴 `#C0392B` |
  | 2 | 比较直接 | Direct / Blunt | 🟠 `#E67E22` |
  | 3 | 比较礼貌 | Polite Request | 🟡 `#D4A017` |
  | 4 | 礼貌 | Respectful / Courteous | 🟢 `#7FA650` |
  | 5 | 委婉 | Indirect / Tactful / Implicative | 🟩 `#2E8B57` |

- **两种特殊语用风格**（勾选后作为额外的第 6、7 条单独呈现）：

  | 档位 | 中文 | 英文 | 色条 |
  |---|---|---|---|
  | 6 | 强硬 | Assertive / Forceful | 🟣 `#7D5BA6` |
  | 7 | 撒娇 | Coaxing / Endearing | 🩷 `#D96BA0` |

- **四种应用场景**：同事平级之间 / 对待上司 / 对待师长 / 对待事务机构或陌生人（积分 ≥ 10 自动解锁，无需刷新页面）
- **四种目标语言**：普通话汉语 🇨🇳 / 香港粤语 🇭🇰 / 英语 🇬🇧 / 法语 🇫🇷
- **双行语用解读**：每个版本下方附「语言特征」与「语用特征」两行分析，各 20–30 字
- **一键复制**：点击按钮直接写入剪贴板，无需 Ctrl + C
- **红心收藏**：任意改写结果可收藏，在个人专区统一查看
- **自动语言识别**：自动判断输入文本属于哪种语言，并可手动修正
- **数据持久化**：历史、收藏、昵称、积分保存在浏览器本地，刷新不丢失，支持导出 JSON

### 双引擎设计

| 引擎 | 触发条件 | 特点 |
|---|---|---|
| **A 轨：大模型** | `.env` 中配置了 API Key | 自然度高，四种语言全覆盖，语用分析逐句生成 |
| **B 轨：离线模板** | 未配置 Key，或大模型调用失败 | 零配置、零成本、开箱即用，用于演示与教学 |

> 程序会**自动降级**：大模型超时、余额不足、网络不通时，自动切换到离线模板，页面不会白屏。

## 安装步骤

### 前置条件

- **Python 3.9 或更高版本**（在终端输入 `python3 --version` 查看）
- 不需要数据库，不需要 Node.js

### 第一步：下载代码

```bash
git clone https://github.com/你的用户名/2p-rephraser.git
cd 2p-rephraser
```

> 还没上传到 GitHub？直接把项目文件夹解压到本地，然后 `cd` 进去即可。

### 第二步：（推荐）创建虚拟环境

虚拟环境可以避免和你电脑上其他 Python 项目冲突。

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

激活成功后，命令行前面会出现 `(venv)` 字样。

### 第三步：安装依赖

```bash
pip install -r requirements.txt
```

### 第四步：（可选）配置 API Key

不配置也能运行，只是会走离线模板模式。想要最好的效果就配上：

```bash
# macOS / Linux
cp .env.example .env

# Windows
copy .env.example .env
```

然后用任意文本编辑器打开 `.env`，把这一行的密钥换成你自己的：

```
LLM_API_KEY=sk-你的DeepSeek密钥
```

> DeepSeek 密钥在 <https://platform.deepseek.com> 的「API keys」页面创建。
> `.env` 已被 `.gitignore` 排除，**不会**上传到 GitHub。

### 第五步：运行

```bash
python app.py
```

看到下面这样的输出就成功了：

```
 * Running on http://127.0.0.1:5000
```

打开浏览器访问 <http://127.0.0.1:5000> 即可使用。按 `Ctrl + C` 停止服务。

## 使用说明

### 改写一句话

1. 在**任务执行区**的文本框输入要改写的句子（最长 200 字符，右下角有实时计数）
2. 选择**应用场景**（同事平级 / 上司 / 师长 / 机构或陌生人）
3. 选择**目标语言**（普通话 / 粤语 / 英语 / 法语）
4. 如需额外的「强硬」「撒娇」两条变体，勾选下方的复选框
5. 点击 **开始改写**

结果会以卡片形式从上到下依次呈现，顶部色条从红到绿代表礼貌程度递增。

### 收藏与复制

- 点击卡片右下角的 **♡ 收藏**，该条会加入个人专区的收藏夹；再点一次取消
- 点击 **⧉ 复制**，文本直接进入系统剪贴板，粘贴即可使用

### 查看历史

进入**历史改写存储区**，会看到四个语言方块（含地区旗与记录条数）。点进任一分区，可以看到该目标语言下的全部历史请求；点击某条记录的标题即可展开，查看当时生成的全部改写结果。

- **修正**：自动语言识别在短句上可能出错，点这里可以手动改正「原文语言」标注
- **删除 / 清空本区**：管理历史数据

### 积分与解锁

每提交一次改写请求积 **1 分**。积分达到 **10 分**后，「对待事务机构或陌生人」场景会自动解锁 —— 不需要刷新页面，下拉框会立即变为可选。

### 导出研究数据

个人专区底部的 **导出全部数据 (JSON)** 会下载一个包含全部历史、收藏、积分的 JSON 文件，可用于后续的语料分析。

## 常见问题

**Q：端口 5000 被占用怎么办？**
A：macOS 的 AirPlay 会占用 5000 端口。在 `.env` 里加一行 `PORT=5001`，或直接改 `app.py` 最后一行的默认端口。

**Q：页面显示「离线演示模式」，怎么切成大模型？**
A：确认三件事：① 项目根目录有 `.env` 文件（不是 `.env.example`）；② 里面的 `LLM_API_KEY` 已经换成真实密钥；③ 改完之后**重启了** `python app.py`。

**Q：提示"大模型调用失败，已自动切换到离线模板"？**
A：常见原因是密钥错误、账户余额为 0、或网络连不上 API。终端里会打印具体的错误类型，可以照着排查。

**Q：复制按钮没反应？**
A：现代剪贴板 API 需要 HTTPS 或 localhost 环境。用 `http://127.0.0.1:5000` 访问是正常的；如果通过局域网 IP 访问，程序会自动降级到旧版复制方案。

**Q：换了电脑，历史记录不见了？**
A：数据保存在浏览器本地存储里，不会跨设备同步。请在个人专区用「导出全部数据」做备份。

**Q：可以改成多人共用、数据存服务器吗？**
A：可以。把 `static/js/storage.js` 的读写换成后端 API，在 `app.py` 里接一个 SQLite 数据库即可 —— 前端其他代码不用动，这也是当初把存储逻辑单独抽成一个文件的原因。

## 能力边界与已知局限

本项目是教学 / 研究辅助工具，以下几点请务必知悉：

1. **离线模式下的英语与法语无法真正翻译。**
   离线引擎采用「交际意图识别 ＋ 预置语用框架」的方案，输出的是该意图下地道的英文 / 法文五档表达，在**语用学上是准确的示例**，但**不保证与你的原句逐字对应**。要得到贴合原句的英 / 法改写，请配置 API Key。

2. **离线模式下的粤语是「词汇替换 ＋ 简繁转换 ＋ 框架套用」。**
   常见句子够用，遇到复杂句式会有生硬的地方。另外，离线引擎只做「普通话 → 粤语」的单向转换，
   如果你输入的本来就是粤语、目标语言选普通话，离线模式不会把它转回普通话（大模型引擎可以）。

3. **语言自动识别是规则法。**
   很短的句子（如「你好」）在普通话 / 粤语之间可能误判；不带重音符号书写的法语可能被判成英语。历史记录里提供了「修正」按钮作为补救。

4. **积分存储在浏览器本地，技术上可被修改。**
   这是纯前端存储的固有特性，作为教学工具不影响使用。

5. **离线模式下的挑战评分只看语言形式，不理解语义。**
   规则引擎检测的是「有没有称呼语、敬称、缓冲语、疑问句式」这类形式特征，
   它无法判断一句话有没有答到题——一段和题目毫无关系但形式完备的话，
   在离线模式下也可能拿高分。**离线分数只适合当作练习时的即时反馈，
   不能作为研究数据使用**；配置 API Key 后由大模型评分才具备语义判断能力。
   页面上会明确标注本次是哪个引擎打的分，导出的 CSV 里也有 `评分引擎` 一列。

5. **大模型输出存在随机性。**
   同样的输入两次生成的结果可能不同。用于正式研究时，请保留原始输出记录（可用导出功能）。

## 部署到线上

> ⚠️ **GitHub Pages 无法运行 Flask**（它只能托管静态网页）。所以「代码放 GitHub」和「网站在线可访问」是两件事。

代码上传到 GitHub 后，可以用下面任一免费平台一键部署成真正的在线网址：

### 部署后必须配置的环境变量

在 Render 的 **Environment** 标签页里添加：

| 变量名 | 值 | 说明 |
|---|---|---|
| `LLM_API_KEY` | `sk-...` | 你的 DeepSeek 密钥 |
| `LLM_BASE_URL` | `https://api.deepseek.com` | |
| `LLM_MODEL` | `deepseek-chat` | 以 DeepSeek 官方文档的当前模型名为准 |
| `ACCESS_CODE` | 你自己定的口令 | 留空 = 不设口令，任何人可用 |
| `DAILY_LIMIT` | `100` | 全站每日大模型调用上限 |
| `PER_IP_DAILY_LIMIT` | `20` | 单个访客每日上限 |

**关于访问口令的强度，请务必知悉**：口令是明文比对的，拿到口令的人可以转发给任何人，它挡的是"偶然点进来的陌生人"，不是有意攻击者。真正兜底的是 `DAILY_LIMIT` —— 它保证最坏情况下当天的损失是可控的固定值。这个强度适用于"发给导师和几位受试者试用"；如果将来要正式公开发布，应该换成真正的用户账号系统。

**关于用量计数**：计数保存在服务器内存里，Render 免费版实例休眠或重新部署后会清零。这意味着极端情况下当天的实际调用次数可能超过上限。要严格计数需要接一个数据库，对当前规模属于过度设计。

### 方案 A：Render（推荐，最简单）

1. 访问 <https://render.com>，用 GitHub 账号登录
2. 点击 **New → Web Service**，选择你的 `2p-rephraser` 仓库
3. 填写配置：
   - **Build Command**：`pip install -r requirements.txt`
   - **Start Command**：`gunicorn app:app`（需要在 `requirements.txt` 里加一行 `gunicorn`）
4. 在 **Environment** 标签页添加环境变量 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`
